# Meadowlane Bank policy library (synthetic)

Meadowlane Bank plc is fictional. These documents were written for the Casebook prototype. They are loosely modelled on UK rules (FCA DISP, Consumer Duty, FG21/1, the Payment Services Regulations 2017) but they are not legal summaries and must not be relied on.

Each clause has a stable ID (for example `POL-04 §2.1`). Casebook only answers from these clauses and must cite the ID for every claim.
