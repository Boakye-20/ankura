Ankura AI by Design · practical build · Scenario 1: complaint handling

Complaints Workbench for Meadowlane Bank

An AI-assisted workbench for complaint handlers at a fictional UK retail bank. It finds the relevant policy, drafts a response that cites it, and builds a complete handover pack for specialist teams. Personal data is masked before any AI processing, every output is checked by code, and no response reaches a customer without a named member of staff approving it.

2 · How it works

Six controlled steps, ending with a named decision-maker

The model only processes masked text and only answers from the bank's approved policy library. If any check fails, the case goes to a person instead of the system guessing.

Step 1

Mask personal data

Rules and name lists replace personal data with tokens before any model call.

Step 2

Triage

Product, issue, vulnerability, regulatory clock and confidence, as structured output.

Step 3

Retrieve policy

Search across 11 synthetic policy documents, indexed clause by clause.

Step 4

Draft

Response and handover pack, with every statement citing a clause ID.

Step 5

Verify

Code confirms citations exist, amounts sit within authority limits and no injection is present.

Step 6

Human decision

Handler approves, amends or escalates. Vulnerable and low-confidence cases need senior co-approval.

3 · Build environment

One repository, one hosted link, testable without a key

Assessors should be able to open and test it in a minute. The hosted site runs in demonstration mode by default, using outputs saved from real model runs. A live mode calls the model through the server, with a spend limit.

Code: GitHub

  • Public repository, e.g. ankura
  • README with a five-minute test route
  • Synthetic data, prompts and test results all versioned

You create the empty repository; I build into it and you review each step.

Application: Next.js on Vercel

  • Same stack as your momentum screener
  • Free hosting, signed in with GitHub
  • Server-side API routes keep the key private

A stable hosted URL reads as client work.

AI: Claude, built with Claude Code

  • Smaller model for triage, larger for drafting
  • Structured outputs so code can verify them
  • Copilot Studio comparison drawn from your Oakbrook work

Needs an Anthropic API key with a low monthly limit, around £10.
